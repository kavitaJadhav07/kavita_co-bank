## 🚀 Installation and Execution

1. Install Python 3 from https://www.python.org/downloads/
2. Open the project folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:

```bash
python bank.py
```

## 🔐 Security and Limitations

- PINs are stored as salted hashes, not plain text.
- The JSON data file is not encrypted.
- This is an educational simulation, not a real banking system.
- Never use real banking PINs or sensitive customer information.
- Do not publish private account data to a public repository.
